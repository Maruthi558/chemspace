# Firebase Development & Agent Skills Rule

Always look for and use the appropriate **Firebase agent skills** to perform tasks related to Firebase:
- `firebase-basics`: Foundational CLI setup, version checks, and configuration.
- `firebase-auth-basics`: Authentication setup, providers (Google, Email/Password, Phone SMS, Email Link), and token management.
- `firebase-firestore`: Cloud Firestore database setup, data modeling, indexes, security rules, and Web SDK queries.
- `firebase-security-rules-auditor`: Security rules assessment and auditing.
- `firebase-hosting-basics`: Classic static site hosting and redirects/rewrites configuration.
- `firebase-ai-logic-basics`: Firebase AI Logic and Gemini API integrations.
